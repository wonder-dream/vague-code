## 细纲

### 1. 一句话说清楚（~30 行）

- "你告诉它要做什么，它自己读代码、写代码、跑测试"
- 类比：不是补全代码的助手，是能独立完成任务的新同事
- 一句话区别：Copilot = 你写它补，ChatGPT = 你问它答，Coding Agent = 你布置任务它独立完成

### 2. 和 Copilot/ChatGPT 的区别（~50 行）

- 三种模式对比表（交互方式 / 自主程度 / 适用场景 / 典型产品）：

| 维度 | 补全模式（Copilot） | 问答模式（ChatGPT） | 自主模式（Coding Agent） |
|------|-------------------|-------------------|----------------------|
| 交互方式 | 你写代码，它补全 | 你提问，它回答 | 你布置任务，它独立完成 |
| 自主程度 | 低——你全程主导 | 中——一问一答 | 高——自主拆解/执行/验证 |
| 工具使用 | 无 | 无（ChatGPT 有插件但受限） | 读/写/搜索/定位/命令/测试 8 个工具 |
| 工作记忆 | 当前文件 | 会话上下文 | 五层压缩 + 跨会话记忆 |
| 典型场景 | 编码时的行级补全 | 问答、explain、debug | 修 Bug、加功能、重构、评测 |

- 自主模式的工作流程简介：任务 → 拆解 → 搜索 → 读取 → 修改 → 验证 → 汇报

### 3. 一次完整任务的旅程（~80 行，含 ASCII 流程图）

**案例：** "修一下 stats.py 的除零 bug"

```
  你                              XClaw
  │                                │
  ├─ "修一下 stats.py 的除零 bug" ─→│
  │                                │
  │                                ├─ [搜索] grep "除以" → 找到除零位置
  │                                │
  │                                ├─ [读取] read_file(stats.py)
  │                                │
  │                                ├─ [分析] 发现 bug：分母未经零值检查
  │                                │
  │                                ├─ [修改] patch → 加 if denominator == 0
  │                                │
  │                                ├─ [验证] bash "pytest tests/test_stats.py"
  │                                │
  │                                ├─ 测试通过 ✓
  │                                │
  │                                └─ "修好了，加了零值检查" ←──┤
  │
  ✓ 完成
```

- 每个步骤标注 Agent 使用了什么工具、产生了什么输出
- **核心素材：** `tests/_target_bug/src/stats.py` 案例

### 4. Agent 的能力清单（~60 行）

- 能力分类表格：

| 能力 | 对应工具 | 一句话示例 |
|------|---------|-----------|
| 读代码 | `read_file` | "看看 src/main.py 的内容" |
| 写代码 | `write_file` | "创建一个新的模块文件 utils.py" |
| 精确修改 | `patch` | "把第 23 行的 pass 改为 continue" |
| 搜索文件 | `glob` | "找到所有 test_*.py 文件" |
| 搜索内容 | `grep` | "搜索 add_user 函数在哪里定义" |
| 执行任务 | `bash` | "运行 pytest 看看测试是否通过" |
| 跨会话回忆 | `memory_search` | "之前用户提到过什么偏好？" |

- 强调：它"先读后改""改完要测"的守则（由 SystemPrompt 强制执行，`context.py:11-16`）

### 5. XClaw 的特别之处（~80 行）

每个特性一句话通俗解释 + 一个小例子，不涉及代码细节：

- **上下文压缩：** 自动压缩旧对话，长会话不丢信息。就像你看书时自动做笔记，不会翻到后面忘了前面
  - 例子：20 轮对话后 Agent 仍然记得你最开始提到的需求

- **权限系统：** 四级安全模式保护你的代码。危险操作要先问你"可以吗？"
  - 例子：Agent 想删除文件→弹窗确认→你按 Y 才放行

- **跨会话记忆：** Agent 记住你的偏好和历史解决方案，下次自动使用
  - 例子：昨天你告诉它"用 pytest"，今天它自动用 pytest

- **工具并发：** 多个不冲突的操作同时执行，速度更快
  - 例子：同时搜索 3 个不同的文件，一次完成

- **可评测：** 跑分验证每个设计决策，数据驱动改进
  - 例子：并发调度使通过率从 83% 提升到 93%

### 6. 你需要准备什么（~40 行）

- Python 3.12+：`python --version` 验证
- uv 包管理器：`pip install uv`
- API Key：DeepSeek（https://platform.deepseek.com/api_keys）或 Anthropic
- 一个想要改进的项目（Git 仓库）
- 安装命令代码块：

```bash
git clone <xclaw-repo-url>
cd xclaw
uv sync
echo 'DEEPSEEK_API_KEY=sk-xxx' > .env
```
